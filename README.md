<h1><img src=".github/readme-icon.png" width="44" height="44" align="absmiddle" alt=""> Open RotMG / Single Player</h1>

Desktop launcher for playing Open RotMG offline with local saves.

**Source preview only.** No player download yet.

The Options panel checks authenticated paired server/client/Ruffle/data updates. Running games are never restarted for an update. Saves and accumulating full backups stay outside the installation; launcher/Electron self-update is not included.

Developer setup and testing: `docs/development.md`. Runtime format, native gates and draft-promotion procedure: `docs/runtime-updates.md`.
